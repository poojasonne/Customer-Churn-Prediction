About StayWise

StayWise is an enterprise customer churn intelligence platform built on Python, Flask, and an optimized Scikit-Learn Random Forest Classifier. The system models multivariate customer behavior patterns across contract commitment, monthly and cumulative spend, technical support presence, and network infrastructure to calculate high-precision retention probabilities.

Algorithm
Random Forest (200 Trees)
Pipeline with StandardScaler
Dataset
Telco Customer Churn
Stratified 80/20 Split
Inference Backend
Flask REST API + SQLite
Persistent historical auditing
Visualization
Chart.js Canvas
Real-time analytics engine
